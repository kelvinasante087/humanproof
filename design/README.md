# HumanProof — Design

The visual direction for HumanProof, and the home for exported design assets (screens, logo, cover).

## Direction

- **Deep-navy credential card** — the core object: the reusable proof-of-human credential, presented like a physical ID card.
- **Teal verification mark** — the "verified human" signal, used on the verify page and badges.
- **Indigo action** — a single accent reserved for the primary action (prove, claim, post).
- **Tone** — clean and instrument-grade. Hierarchy comes from weight, size, and spacing, not decoration.

## Responsive

Mobile-first, desktop-graceful. The World Selfie Check is a phone moment, so the flow is designed for the phone first and scales up cleanly to desktop.

## Workflow

Identity + colors → **Google Stitch** (with Claude) → edited → **Figma** → exported here. Every step directed, edited, and verified by Kelvin.
